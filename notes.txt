HTTP vs HTTPS
HTTP:
- Data sent as plain text
- Anyone on the network can read it
- Uses port 80
- No padlock icon in the browser
HTTPS:
- Data is encrypted before sending
- Unreadable even if intercepted
- Uses port 443
- Shows a padlock icon in the browser
Local Storage vs Session Storage
Lifetime:
- Local Storage: Stays until manually cleared
- Session Storage: Cleared when tab is closed
Scope:
- Local Storage: Shared across all tabs of same site
- Session Storage: Limited to a single tab
Typical size:
- Local Storage: 5-10 mb per origin
- Session Storage: ~5 mb per origin
Best for:
- Local Storage: Long term preference (theme, language)
- Session Storage: Temporary data for one visit
Type Conversion
Implicit: Done automatically
- "5" + 3; -> 53
- "5" - 3; -> 2
- 1 + true -> 1
Explicit: Done manually
- Number("42") -> 42
- String(100) -> "100"
- Boolean(0) -> false
- Boolean("") -> null [Note: or false depending on language context]
- Boolean("hi") -> true

Axions

- Axions is a 3rd party promised-based https client (HTTP) used to make HTTP requests (calling an API) from the browser in an easy and better way.
- We can say, Axions is the upgraded version of fetch method.
- Almost 70% of React users use axions to make HTTP requests for backend like Node JS.

Fetch vs Axions:

1. Fetch:
- Use parse method to use JSON format
- Need to use more then() [Need to use multiple .then()]
- Provide... [Basic features]
- Built in browser (no install needed)
2. Axions:
- By default use JSON format
- Need to use only one then()
- Provide all type of HTTP method
- Better error handling
- Third party package (npm install)
Additional Notes:
- Installation: npm install Axions
- Rectify the code based on the status code.
- Request and response handled by Axios.
